# 読み上げ修正

合成した読み上げ音声（講演録・書籍の1講／1章）を iPhone で聞きながら、読み・抑揚・間のおかしな所を指摘し、Macが作った代案を聞き比べて評価するためのウェブアプリです。**修正作業のための道具**で、仕上がった音声はこれまでどおりミュージックアプリで聞きます。

- iPhoneのSafariだけで動きます（ホーム画面に追加するとアプリのように使えます）。
- 追加の課金はありません。音声を作るのはMac（ローカルの合成器）、受け渡しは iCloud Drive です。
- 音声・本文・指摘はこの端末のブラウザの中にだけ保存されます。どこにも送りません。**このリポジトリには本文や音声を置きません**（訳文には著作権があるため）。

公開先: **https://yinamori-bot.github.io/tts-review/**

## 流れ

```
Mac                                   iCloud Drive/シュタイナー読み上げ/修正作業/            iPhone（このアプリ）
review/export.py ──→  <講>.m4a ＋ <講>.json  ──→  取り込む → 聞く → ⚑指摘
review/inbox.py  ←──  指摘_<講>.json         ←──  Macに渡す（ファイルに保存）
代案を作る
review/reply.py  ──→  返事_<講>_<日時>.json  ──→  取り込む → 元→案 で聞き比べ → ◎採用 / △惜しい / ×不可
                                                     → Macに渡す
```

Mac側のスクリプトは `steiner-reader/review/` にあります（このリポジトリには入っていません）。ファイルの形は [`docs/FORMAT.md`](docs/FORMAT.md)。

## 使い方

1. **取り込む**：一覧の「ファイルを選ぶ」で、iCloud Drive の「修正作業」フォルダから講の `.m4a` と `.json` を**一緒に**選ぶ。
2. **聞く**：講を開くと本文が出て、いま読んでいる文が黄色く光り、自動で追いかけます。
   - 文をタップするとそこへ移ります。
   - 指で本文を動かすと追いかけを止めます（「現在地へ」で戻ります）。
   - 速さは左下のボタンで 0.8〜1.5倍。
   - **印**：文の左端（小さな丸）をタップすると赤い印が付き、もう一度タップで消えます。再生は止まりません。気になった所に印だけ付けて聞き進め、あとで「● 次の印へ」で印の文へ飛び、⚑ 指摘 で入力します。指摘を保存すると、その文の印は自動で消えます。
3. **指摘する**：おかしいと思ったら **⚑ 指摘**。音が止まり、設定した秒数（初めは1秒）だけ前の文が選ばれます。
   - 文が違えば ‹ › で前後に動かし、「▶ この文を聞く」で確かめます。
   - 気になる語の最初の字と最後の字をタップ。
   - 種類を選びます：読み（正しい読みをひらがなで）、抑揚（仮名1字ごとに 高U・低D）、間（長すぎる・短すぎる・ここで間がほしい・ここで切らないで）、語尾の切れ、音の崩れ、誤植、その他。
   - メモはキーボードのマイクで話しても入れられます。
4. **Macに渡す**：「指摘」タブの「Macに渡す」→「ファイルに保存」→「修正作業」フォルダへ（同じ名前のファイルは置き換え）。そのあとMacのClaudeに「指摘を見て」と頼みます。
5. **代案を評価する**：Macが置いた `返事_….json` を同じ「ファイルを選ぶ」で取り込みます。
   - 指摘のカードの中に「提案」の枠が出て、案がいくつあっても一枚にまとまります。
   - 「元の音」と各案は、それぞれの ▶ で別々に鳴らせます。
   - 案ごとに ◎良い / ○可 / △惜しい / ×不可 とコメントを付けます。
   - 最後に「最終判断」で、どれか一つの案を選びます（「案1にする」など）。全部だめなら「全部不採用」を押し、新しい指示を書きます。案が一つだけのときも同じです。
   - 終わったらまた「Macに渡す」。全部不採用にした指摘には、新しい案が同じカードに足されて返ってきます。
6. 直った音声が届いたら、新しい `.m4a` と `.json` を取り込み直します。前の版の指摘は残り、「前の版」と表示されます。通しで聞いて問題がなければ「この講は合格」に印を付けます。

## 注意

- ブラウザのデータを消すと、取り込んだ音と指摘も消えます。指摘は「Macに渡す」で書き出したファイルが iCloud に残ります。
- 1講ぶんの音は 15〜20MB ほどです。使い終わった講は「指摘」タブのいちばん下で消せます。
